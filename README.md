# Brotato-FengAddMods

为《Brotato》（土豆兄弟）新增大量角色、武器与物品的内容型 Mod。

- Steam 创意工坊：<https://steamcommunity.com/sharedfiles/filedetails/?id=3768330140>

## 安装

1. 通过 Steam 创意工坊订阅本 Mod（推荐）。
2. 或手动将本目录放入游戏的 mods 目录（1.2.0 起无需任何第三方依赖）。
